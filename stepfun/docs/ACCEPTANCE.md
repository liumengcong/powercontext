# 提交前最后验收

这份清单帮助生成题目要求的真实浏览器证据。已验证状态见 README，不把下面未运行项目自动视为通过。

- [ ] Chrome 或 Edge：自动模式加载模型，界面记录实际后端。
- [ ] 导入自己的文本文件，观察浏览器向量化进度及 seekdb 写入/刷新计时。
- [ ] 查询返回对应原文；Network 中无云端 embedding API。
- [ ] 增量新增文本后可立即查询；重复相同导入不重复计数。
- [ ] 切换知识库、切换模型精度后，结果属于当前集合。
- [ ] 重启应用，再次加载相同模型配置，原知识库仍可查询。
- [ ] WebGPU 可用环境：记录是否实际执行成功；若量化算子失败，保留原因。
- [ ] WebGPU 不可用环境：自动降级 WASM，仍完成导入和查询。手动 WASM 测试单列。
- [ ] 完整评测 12 轮，检查每轮 completed、actualBackend 和 error，导出 JSON。
- [ ] 生成汇总并补入一页说明，附设备准确型号、显卡、操作系统和浏览器版本。
- [ ] 保留原始失败记录；没有测得的数字写“未测得”，不选取最好一次代替中位数。
