## 调试修复

独立验收复现后由 Qoder 修复：

1. `.map(memoryCard)` 把数组下标误传给第二参数，改为箭头包装。
2. 同序号并发请求同时成功，改为单进程 `asyncio.Lock` 包含完整读、比较、写流程；去掉锁时同一回归测试实测失败，恢复后通过。
3. 已遗忘偏好仍影响续学，改为核心推导只读取 active 记忆。
4. 500 条事件截断导致旧状态复活，改为全分页读取，并用 520 条真实事件验证。
5. 错误结构与 DELETE 参数不一致，统一前后端解析与传参。
6. 断线健康检查仍返回成功，改为真实 HTTP 503。
7. 修复弹窗常驻、长文本溢出、总览显示状态 JSON 等界面问题。

详细的成功与失败记录见 `验证结果.md`。演示数据均为合成数据，尚无真实用户提效统计。

## 工具分工

Qoder 承担主要编码、测试、修复、演练脚本、初始站点及文档。Codex 协助需求准备、独立缺陷复现、原生浏览器走查、证据整理、文档事实校正、通过 Qoder Sites CLI 发布、仓库提交与打包。未将其他工具编写的主程序冒充 Qoder 产出。
