## 3. 演练过程中真实出现过的失败（未隐藏）

| 时间 | 现象 | 根因 | 处理 |
| --- | --- | --- | --- |
| 19:10 | 演练第 6 项 FAIL，`content_type=null` | 脚本用 `dict(response.headers)` 后按 `Content-Type` 取值，urllib 的 key 是小写 | 增加 `_header()` 大小写不敏感读取（`docs/evidence/20261116-111834` 保留该次失败） |
| 19:26 | 演练第 5 项 FAIL，`isolation_count_before_write=1` | 隔离演练工作区名固定，第二次运行时已有上一条测试记忆 | 改为每次运行使用带时间戳的新工作区名（`docs/evidence/20261116-112620` 保留该次失败） |
| 之前 | `/api/status` 的 `database` 显示 `Users/...`（丢了开头的 `/`） | `Settings.database_path` 用 `rsplit("///")` 反解 URL | 改为直接保存 `database_path` 字段，URL 由它拼出；绝对路径也做了归一化 |
| 之前 | 断开演练报 `ValueError: Token ... powercontext_provider_observer ... was created in a different Context` | 在请求上下文里退出 `open_builtin_runtime` 的 AsyncExitStack | runtime 改由一个宿主任务进入/退出，`stop()` 只发信号并等待该任务 |
| 之前 | 过期 `forget` 返回 500 而不是 409 | 冲突判定只认包含 “revision” 的异常文本 | `_is_conflict` 改为按异常类型与 `code` 集合判定（`atomic_memory_changed` 等） |
| 19:21 | 界面截图里“出处”弹窗常驻、右侧内容溢出 | `.modal { display:flex }` 覆盖了 `hidden` 属性；长 JSON 文本不会换行 | 加 `[hidden]{display:none!important}`；`.mem-text/.mono` 允许断词，栅格用 `minmax(min(300px,100%),1fr)` |
| 19:21 | 总览“最近学习记录”显示状态事件 JSON 原文 | 未按类别过滤 | 总览过滤掉 `kind=task_status`，记忆库新增类别筛选（可选 `task_status`） |

外部验收提出的 7 项问题逐条对应：`frontend/app.js` 的 `map(memoryCard)` 已改为箭头包装；
状态写入已放进单进程 `asyncio.Lock`；核心推导只读 `state=active`；状态事件改用 `store.list_all()`
全分页读取并在列表接口明示 `has_more`；前端错误解析兼容 `detail.error` 与扁平 `detail`，
遗忘按钮改用 DELETE 查询参数；`/api/health` 未连接时返回 503、状态探测异常时 `connected=false`；
空态与站点材料见下。
